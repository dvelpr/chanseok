# Chanseok Site v2

Curated static site built from 20 selected pages of the supplied PDF.

## Deploy to Cloudflare Pages
1. Replace your existing GitHub repository files with the contents of this folder.
2. Commit the changes.
3. Cloudflare Pages should redeploy automatically.
4. If needed, trigger a new deployment from Cloudflare Pages.

No build command is required. The site is plain HTML/CSS/JS.
