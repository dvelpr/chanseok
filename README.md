# Chanseok Archive — Expanded Edition

Open index.html in any modern browser. No installation, server, account, or internet connection is needed.

Includes:
- Four local archive images (the original profile slide and three supplied memes).
- Keyboard-accessible image viewer: Enter/Space to open, arrow keys to browse, Escape to close.
- Scroll-powered CFO gauge with coffee boosts and a coffee reset.
- Three-answer interview mini-game.
- Eight fictional corporate phrases with plain-English translations.
- Toggleable 3×3 meeting bingo with row, column, diagonal detection, and reset.
- Three boardroom field notes, a fictional daily schedule, and expandable FAQs.
- Mobile layouts and support for reduced-motion preferences.

This is an unofficial fan-made humor page. Added captions, answers, phrases, and metrics are fictional, not factual statements or actual quotations. Speech bubbles are embedded in the supplied images. No analytics or data collection are included.

Edit index.html for page content, style.css for styling, and script.js for interaction behavior. Images are in assets/.
